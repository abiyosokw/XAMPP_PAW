# KANTIN PESAWAT THE SKELD

## Menjalankan

Buka folder proyek di web server PHP lokal. Contohnya dengan menjalankan:
```bash
php -S localhost:8000
```
dari folder ini, lalu buka `http://localhost:8000` di browser.
Bisa juga melalui Apache/XAMPP.

## Letak file per level

- **Level 1:** `level1/form.php`, `css/style.css`
- **Level 2:** `level2/hitung.php`
- **Level 3:** `level3/simpan.php`, `level3/struk.php`
- **Level 4:** `level4/ingat.php`, `level4/sapaan.php`

File `index.php`, `proses.php`, dan `ringkasan.php` menghubungkan alur halaman aplikasi.
